# Emoji Picker

A searchable collection of commonly used emojis.

## Features

- Emoji search
- Emoji selection
- Clipboard support

## How to Use

Search for an emoji and select it to copy.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
